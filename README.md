# 天翼云用量监视器

天翼云电脑（eaichat.ctyun.cn）Coding 套餐剩余用量悬浮窗监控工具。

常驻桌面的桌宠式小挂件，实时显示近 5 小时 / 本周 / 套餐总量的用量与剩余进度，无需打开网页轮询。

## 功能

- **桌宠悬浮窗**：折叠挂件常驻桌面，点击展开三周期用量进度条图表
- **自动刷新倒计时**：折叠/展开态均可见，点击倒计时栏立即刷新
- **刷新间隔可调**：1 分钟 ~ 1 小时六档循环切换
- **两种凭证获取方式**：
  1. 调试浏览器自动捕获（推荐）：程序拉起 Chrome/Edge 打开登录页，登录后自动截获签名请求头
  2. 手动粘贴 cURL：DevTools → Copy as cURL 粘贴即可
- **凭证过期提醒**：YL-Token 有效期约 7 天，过期后悬浮窗提示重新捕获
- **单实例锁**：防止多开叠窗；挂件位置自动记忆

## 下载

前往 [Releases](https://github.com/Mapleawaa/ctyun-codingplan-monitor/releases) 下载：

- `天翼云用量监视器.exe` — 单文件版，双击即用
- `天翼云用量监视器-windows-x64.zip` — 目录版，解压运行

## 使用

1. 双击运行，首次会进入配置向导，按提示登录天翼云账号并触发一次用量请求
2. 凭证保存在 EXE 同目录的 `config.json`（仅保存在本机，不会被上传）
3. 之后悬浮窗自动刷新；凭证过期后按提示重新走一遍捕获流程即可

> 接口的签名机制将请求签名与登录身份绑定，无法伪造，因此程序采用「捕获一次真实请求后原样回放」的方式工作。

## 从源码构建

```bash
uv sync
uv run ctyun-monitor          # 直接运行
uv run pyinstaller --noconfirm --clean --onedir --console --name "天翼云用量监视器" --paths . run.py
```

推送 `v*` 格式的 tag 会自动触发 GitHub Actions 构建并创建 Release。
